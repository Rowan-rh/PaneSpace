# 当前缺失功能清单

本文汇总 PaneSpace 当前尚未实现或仍不完整的功能，作为后续开发的工作清单。内容依据仓库路线图、产品说明、开发指南、架构决策和设置页中的计划项整理；它不是版本承诺或发布时间表。

更新时间：2026-09-25

## 状态说明

- `[ ]` 尚未完成。
- `[~]` 已有基础实现，但能力、体验或可靠性仍不完整。
- 完成一项后，应同时补齐相关测试、文档和界面验证，再勾选。
- 已分阶段的项目沿用[开发路线](ROADMAP.md)中的阶段；“待排期”表示路线图还没有确定阶段。

## 文件操作与性能

路线图：0.2 — Reliable file operations

- [ ] **字节级传输进度与可取消的大文件传输**：目前显示项目级进度；单个 `FileManager.copyItem` 调用不能中途取消，见 [ADR 0006](adr/0006-staged-local-transfers.md)。
- [ ] **持久化操作历史**：应用重启后仍可查看已完成、失败或取消的操作记录。
- [ ] **可撤销操作**：在 macOS 支持恢复的范围内提供撤销，并清楚说明无法撤销的操作。
- [ ] **大目录渐进加载**：避免一次性读取和展示大量条目造成界面停顿；支持取消过期加载。

## 浏览与日常工作流

路线图：0.3 — Views and workflows

- [ ] **图标网格和图库视图**：支持切换视图、调整图标尺寸，并保持文件选择和键盘操作可用。
- [ ] **命名工作区**：保存和恢复用户主动创建的工作区；与当前自动恢复上次会话及侧栏快捷方式区分。
- [x] **多选与范围选择（访达式）**：列表与分栏视图均支持 Shift 点按范围、Command 点按增减、Shift+方向键扩展和 Command-A 全选。按住 Shift 点按范围末项应选中起点到终点之间的连续项目；按住 Command 点按应可逐项添加或取消非连续选择。行为参考 [Apple 关于在 Mac 上选择多个项目的说明](https://support.apple.com/guide/mac-help/mchlp1378/mac)。
- [ ] **命令面板与可配置快捷键**：提供命令搜索、快捷键录制和冲突检查。当前快捷键固定，设置页只展示快捷键。
- [ ] **压缩包创建和解压**：提供压缩与解压操作，并对冲突和失败给出明确处理方式。
- [ ] **Git 状态标记**：在文件列表中显示仓库状态，同时避免拖慢大型仓库浏览。
- [ ] **批量重命名**：支持预览变更结果，并在执行前检查名称冲突和无效名称。

## 远程存储

路线图：0.4 — Remote providers

> 状态：挂起。0.2 与 0.3 完成前不开发远程存储。

- [~] **Provider 能力报告与通用传输**：`FileProviding` 已采用异步接口，本地 Provider 也已隔离在 actor 中；尚需补充能力报告、Provider 级取消和与存储类型无关的传输执行，见 [ADR 0004](adr/0004-async-provider-primitives.md) 和[开发指南](DEVELOPMENT.md)。
- [ ] **SFTP Provider**。
- [ ] **SMB Provider**。
- [ ] **WebDAV Provider**。
- [ ] **Keychain 凭证存储**：远程凭证只保存在系统钥匙串中。
- [ ] **连接恢复与状态处理**：覆盖重连、超时、认证失败和离线状态，并提供可采取行动的错误提示。

## macOS 集成、权限与发布

路线图：0.5 — Platform integration；1.0 — Stable release

- [ ] **Finder 扩展**：从 Finder 调用 PaneSpace 的相关操作。
- [ ] **分享扩展和临时暂存区**：支持从其他应用接收项目，并在多个位置间暂存文件。
- [ ] **macOS Services 操作**。
- [ ] **Spotlight 集成**：评估并实现适合 PaneSpace 的系统搜索集成。应用内 Quick Look 预览已存在；扩展式 Quick Look 集成需另行评估。
- [~] **辅助功能和本地化审查**：应用已有英文和简体中文界面，仍需系统性检查 VoiceOver、键盘可达性和翻译完整性。
- [ ] **安全作用域书签**：为沙盒分发持久保存用户授权的位置访问。当前文件访问依赖 macOS 授予运行中进程的权限，详见[README](../README.md)。
- [ ] **正式发行签名与公证**：使用 Developer ID 签名并完成 Apple 公证。
- [ ] **自动发布和更新元数据**：建立可重复的版本发布流程和应用更新信息。

## 设置页中标记为计划中的选项

以下设置目前是禁用的占位项；实现时应同步更新设置页，避免选项长期保持不可用。

- [ ] **历史与窗口行为**：最近访问位置和文件、工作区在标签页中打开、退出确认。
- [ ] **鼠标与文件夹行为**：在文件列表中输入时的响应、空白处双击行为、在新标签页打开文件夹、拖放确认、显示上级目录项、展开软件包内容。
- [ ] **路径栏与侧栏**：从路径片段展开文件夹菜单、侧栏放在右侧、显示卷可用空间。
- [ ] **标签页细节**：新标签插入位置、重用空标签、双击关闭标签、单独配置重启后的标签恢复行为。
- [ ] **文件列表元数据**：控制扩展名显示和计算文件夹大小。
- [ ] **搜索选项**：递归或全 Mac 搜索范围、输入时过滤、搜索文件内容、包含隐藏项目。
- [ ] **上下文菜单配置**：选择显示哪些内置命令，以及是否加入 macOS Services；这项指菜单定制，不代表相关文件操作本身都缺失。
- [ ] **快速启动配置**：选择终端和代码编辑器，并支持应用发现、自定义参数和变量展开。
- [ ] **更新与诊断**：Beta 更新选项和诊断日志设置。

设置页还展示了“文件夹同步”卡片，但目前没有对应的路线图阶段；将其作为候选功能评估后再排期。
