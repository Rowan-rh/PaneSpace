## Purpose

让分栏视图在刷新和文件系统变化时保留用户逐列建立的浏览路径与选择，只在用户显式导航时重建列。

## ADDED Requirements

### Requirement: 刷新时保留分栏路径

在分栏视图中，手动刷新、目录变化通知或传输完成触发的刷新 SHALL 原地重新加载当前显示的每一列，保留列的数量、顺序和各列中仍然存在的选中项。只有显式导航（进入路径、前进/后退、切换标签页、打开侧栏位置、返回上级等）SHALL 以目标目录重建列。

#### Scenario: 已展开多列时上层目录发生变化

- **WHEN** 分栏视图显示 A → B → C 三列，且 A 目录中新增或删除了一个文件
- **THEN** 三列仍然保留，A 列显示更新后的内容，B 仍在 A 列中保持选中

#### Scenario: 手动刷新保留分栏路径

- **WHEN** 分栏视图显示多列且用户执行刷新
- **THEN** 所有列重新加载内容，列路径与各列选择保持不变

#### Scenario: 刷新时选中项已被移除

- **WHEN** 刷新时某一列中原先选中的文件夹已不存在
- **THEN** 该列不再保留该选择，该列之后依赖它的列被移除，面板位置回到该列所在目录

#### Scenario: 刷新时某列目录已不可访问

- **WHEN** 刷新时某一列本身的目录已被删除或无法读取
- **THEN** 该列显示不可用提示，其后的列被移除，之前的列保持不变

#### Scenario: 显式导航重建分栏

- **WHEN** 用户在分栏视图中通过后退、路径输入或侧栏跳转到另一个目录
- **THEN** 分栏视图只显示目标目录这一列

### Requirement: 监听所有显示的分栏目录

面板可见时，分栏视图 SHALL 监听当前显示的每一列目录；列表视图 SHALL 只监听当前目录。显示的目录集合变化后，不再显示的目录 SHALL 停止监听。

#### Scenario: 最后一列目录发生变化

- **WHEN** 分栏视图显示 A → B → C，且 C 目录中新增了文件
- **THEN** C 列在短暂去抖后显示新文件，其他列保持不变

#### Scenario: 收起的列不再触发刷新

- **WHEN** 用户在 A 列选择了另一个项目使 B、C 列被移除，随后 C 目录发生变化
- **THEN** 面板不因 C 目录的变化刷新
