- [x] 2.1 `swift test`、`make app`、签名检查、`openspec validate undo-file-operations --strict`。

验证记录：`swift test -Xswiftc -warnings-as-errors` 共 114 项通过；`make app` 与严格签名检查通过。在隔离配置的开发版双面板分栏视图中：重命名文件夹后“编辑”菜单显示“撤销将“New Folder”重命名为“Renamed Folder””，执行后磁盘与面板均恢复原名；实测中发现并修复了在 `/tmp` 下重命名已打开文件夹后标签失效、以及撤销后停留在错误状态的面板不刷新两个问题。键盘 ⌘Z 撤销了新建的空文件夹（移到废纸篓）；在“新建文件夹”对话框文本框中输入后按 ⌘Z 只恢复文字，文件未变化。
